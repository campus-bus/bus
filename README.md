# 环线坐车 - 校园环线时刻表助手

校园环线公交车时刻表查询与到站预测 PWA 应用，服务于国防科大校园师生。

## 功能特性

- **首页推荐**：GPS 定位展示附近站点到站车次，目的地搜索含步行时间与多起点推荐
- **行程规划**：输入出发站、到达站和到达期限，查询可乘坐的车次
- **总时刻表**：按线路/班次/时间查看全部发车记录
- **地图可视化**：静态卫星底图 + SVG 路线叠加，实时公交车位置推算（零地图 API 调用）
- **手动记录**：乘车时手动计时记录站间耗时，数据上传至 Supabase 用于校准预测
- **历史记录**：查看和撤销已提交的乘车记录
- **PWA 离线**：支持添加到手机桌面，离线查看时刻表

## 技术栈

- **框架**：Vue 3 + TypeScript + Vite
- **状态管理**：Pinia
- **UI 组件**：Vant 4
- **地图**：静态卫星底图（ESRI World Imagery）+ SVG 叠加层
- **数据库**：Supabase
- **部署**：GitHub Pages（`docs/` 目录）

## 项目结构

```
src/            前端源码
public/         运行时静态资源（JSON 数据、图标）
scripts/        数据处理脚本（archive/ 为一次性历史脚本）
data/           数据资料（Excel、站点坐标 txt、原始图片、备份）
documentation/  开发文档（制作日志、路段预估方法）
docs/           GitHub Pages 部署产物
```

各文件夹内含 `README.md` 说明职责。开发细节见 `CLAUDE.md`。

## 开发

```bash
npm install
npm run dev        # 本地开发（HTTPS，桌面定位需接受自签名证书）
npm run build      # 构建到 dist/
npm run deploy     # 构建并复制到 docs/，commit + push master 即完成部署
```

## 数据说明

到站时间根据路线站间秒数（基于用户实测校准）和发车时刻估算，实际时间可能受上下客、道路情况和车辆调度影响。数据变更记录见 `CHANGELOG.md`。
